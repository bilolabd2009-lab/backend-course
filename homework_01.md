  Cервис Ozon
1 Поиск товара
2 Добавление товара в корзину
3 Оформление заказа 

Действие 1 — поиск товара

Пользователь вводит название товара.
На сервер отправляется поисковый запрос.
Сервер ищет товар в базе данных.
В ответ возвращается список найденных товаров.
Действие 2 — добавление товара в корзину

Пользователь нажимает «Добавить в корзину».
На сервер отправляется информация о товаре.
Сервер проверяет наличие товара.
Информация о корзине сохраняется.
В ответ приложение показывает обновлённую корзину
Действие 3 — оформление заказа

Пользователь нажимает «Оформить заказ».
На сервер отправляются данные заказа.
Сервер проверяет данные и товары.
Заказ сохраняется в базе данных.
В ответ приложение показывает информацию о заказе.
